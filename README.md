# Bishop Family Hub

Personal FamilyHub monorepo.

The application is split into two deployable parts:

- `frontend/` — the Vite/PWA web app deployed to Vercel.
- `backend/` — the Spring Boot API deployed to DigitalOcean and backed by Neon PostgreSQL.

The original standalone repositories remain the deployment source of record until this monorepo has been verified and intentionally connected to new deployment settings.
